## 快速开始

本地预览：

```bash
npm install
npm start
```

浏览器打开 `http://localhost:4000`。

写新文章：

```bash
npx hexo new "文章标题"
```

然后编辑 `source/_posts/` 下对应的 Markdown 文件即可。
